## [1.0.0] - 2026-04-05

### Added
- Timed GM reminders with configurable interval (5-180 minutes)
- Full voting system: all players vote, GM participates and can override
- Vote monitor dialog with live progress tracking for the GM
- Hero Point awards (PF2e) and Inspiration awards (D&D 5e) with system auto-detection
- Hero Hype system: players send tagged kudos (Roleplay, Tactical, Puzzle Solver, Helper) with optional messages
- Hype posting to chat as anonymous messages
- Customizable heroic quotes in winner announcements
- Snooze options: 1min, 5min, 10min, custom time, or rest of session
- Session winner tracking with greyed-out/hidden repeat winners
- Excluded characters setting for companions, NPCs, and test characters
- Hero Point reroll button on PF2e d20 check chat cards
- Reset Hero Points / Inspiration from the reminder dialog
- Clear award history per session
- Compendium macro for quick access (GM: reminder dialog, Players: hype dialog)
- Socket-based cross-client communication for real-time voting
- Position memory for all dialogs
- VTTools by GM Ant branding
